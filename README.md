# Innonext Sales — ค้นบาร์โค้ด Central + บันทึกยอดขายหน้าร้าน

ระบบสำหรับพนักงานหน้าร้าน CHAAKAN (และ PISCESS ในอนาคต) ที่ขายในห้าง Central:
สแกน/พิมพ์บาร์โค้ดเกาหลีข้างกล่อง → ได้บาร์โค้ด Central ทันที → กด "ขายแล้ว" บันทึกยอด 1 แตะ
CEO/แอดมินดูยอดรายวัน–รายเดือนทางไลน์

## สถาปัตยกรรม
- **โค้ด**: `Sales.gs` เป็นโมดูลใน Apps Script โปรเจกต์ **Innonext HR** (ใช้ตัวตน LINE/พนักงานร่วมกัน — repo [innonext-hr](https://github.com/thipwonh-ship-it/innonext-hr))
  - ปุ่ม `🛍 ขาย / หาบาร์โค้ด` + หน้าต่างขาย อยู่ใน `Index.html` ของ Innonext HR (โชว์เฉพาะพนักงานกลุ่ม "หน้าร้าน")
  - คำสั่งแชท `sales` / `ยอดขาย` เรียกผ่าน `onExecCommand` ใน `Exec.gs`
- **ข้อมูล**: Google Sheet แยก **"Innonext Sales"** (ID เก็บใน Script Property `SALES_SHEET_ID`)
  - แผ่น `สินค้า`: แบรนด์ · รุ่น · สี · ไซส์ (มม.) · ไซส์ Central · บาร์โค้ด Central · ชื่อ Central · บาร์โค้ดเกาหลี · SKU · ราคาเต็ม · หมายเหตุ
  - แผ่น `ยอดขาย`: วันที่ · เดือน · สาขา · พนักงาน · แบรนด์ · รุ่น · สี · ไซส์ · บาร์โค้ด Central · บาร์โค้ดเกาหลี · จำนวน · ราคาเต็ม · ราคาขาย · ส่วนลด · ยอดรวม · หมายเหตุ · ยกเลิก
- `products.csv` = มาสเตอร์ CHAAKAN 652 SKU (จาก CHAAKAN_Central_Barcode_Master 2026-10-07) ที่โหลดเข้าแผ่น `สินค้า` แล้ว

## การใช้งาน
| ใคร | ทำอะไร |
|---|---|
| พนักงานหน้าร้าน | เมนู "ลงเวลา" ในไลน์ → ปุ่ม **🛍 ขาย / หาบาร์โค้ด** → สแกน/พิมพ์บาร์โค้ดเกาหลี หรือ รุ่น สี ไซส์ → เห็นบาร์โค้ด Central ตัวใหญ่ (คัดลอกได้) → ใส่จำนวน/แก้ราคาถ้ามีโปร → **✅ ขายแล้ว บันทึกยอด** · ยกเลิกรายการของตัวเองได้เฉพาะวันนี้ |
| CEO | พิมพ์ `sales` ในแชท OA → ยอดวันนี้ + เดือนนี้ แยกสาขา + รุ่นขายดี (อังกฤษ) · ไม่มีส่งสรุปอัตโนมัติ (v6) — พิมพ์เรียกเอง |
| หนึ่ง (CEO + บัญชี = PAYER_UID) | พิมพ์ `ยอดขาย` (ไทย) + ลิงก์ตาราง CEO (แชร์ Viewer แล้ว) |
| แอดมิน | พิมพ์ `ยอดขาย` (ไทย) · แก้/เพิ่มสินค้าในแผ่น `สินค้า` (ระบบ cache 10 นาที) · ยกเลิกรายการย้อนหลังในแผ่น `ยอดขาย` (ใส่ ✓ คอลัมน์ ยกเลิก) |

## ติดตั้ง (ทำครั้งเดียว — ทำแล้ว 28 ต.ค. 2569)
1. วาง `Sales.gs` ในโปรเจกต์ Apps Script Innonext HR + แก้ `Index.html` / `Code.gs` (`shop` flag) / `Exec.gs` ตาม commit v37 ใน innonext-hr
2. รัน `setupSales()` → สร้างชีต + แผ่น + ทริกเกอร์ `salesDailySummary` 20:xx
3. โหลด `products.csv` เข้าแผ่น `สินค้า`
4. Deploy เวอร์ชันใหม่ของ web app

## สาขาที่เปิดใช้ (v2 — 29 ต.ค. 2569)
- ตอนนี้เปิดเฉพาะ **Mega Bangna** (ค่าเริ่มต้น `SALES_LOCS_DEFAULT` ใน Sales.gs)
- เปิดสาขาเพิ่ม: Apps Script → Project Settings → Script Properties → `SALES_LOCS` = `Mega Bangna, Central World` (ชื่อตรงกับคอลัมน์ ร้าน/สาขา ในแผ่น พนักงาน) — ไม่ต้องแก้โค้ด ไม่ต้อง deploy
- พนักงานสาขาที่ยังไม่เปิด จะไม่เห็นปุ่ม 🛍 ขาย

## ตารางยอดขายสำหรับ CEO (v3 — 29 ต.ค. 2569)
- Google Sheet แยก **"Innonext Sales — CEO Report"** (ID ใน Script Property `SALES_CEO_SHEET_ID`) แผ่น `Sales`: Date · Time · Branch · Brand · Model · Color · Size · Qty · Full/Sale price · Discount · Total · Note — **ไม่มีชื่อพนักงาน** · ไม่รวมรายการที่ยกเลิก · ใหม่สุดอยู่บน · มี filter
- อัปเดตเมื่อพิมพ์ `sales`/`ยอดขาย` และอัปเดตเงียบๆ ทุกคืน 20:xx ไม่ส่งไลน์ (`salesDailySummary` → `salesCeoSync()`) · ลิงก์แนบท้ายข้อความ
- แชร์แบบดูอย่างเดียวด้วยอีเมล Google: `salesCeoShare('a@gmail.com, b@gmail.com')` · CEO ดาวน์โหลดเป็น Excel ได้ (File → Download)

## เพิ่มสินค้า PISCESS / รุ่นใหม่
เพิ่มแถวในแผ่น `สินค้า` (แบรนด์ = PISCESS) — ไม่ต้องแก้โค้ด · ค้นหาใช้ทุกคอลัมน์ยกเว้นหมายเหตุ

## ความปลอดภัย
ไม่มี secret ในโค้ด · LINE token อยู่ใน Script Properties ของ Innonext HR เท่านั้น · ไม่มีข้อมูลลูกค้า
